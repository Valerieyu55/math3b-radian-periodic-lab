## 🌟 核心單元模組

### 📐 單元 01：弧度量 (Radian Measure)
1. **弧度定義與物理展開**：圓弧動態「拉直」比對半徑刻度，直觀感受 1 弳（1 rad）的實數幾何本質。
2. **角度/弧度換算與象限同界角**：多圈正負螺旋角軌跡、象限判定與度數/弧度即時轉換。
3. **扇形弧長與面積實驗室**：即時滑桿聯動半徑與圓心角，動態計算弧長 $s = r\theta$ 與面積 $A = \frac{1}{2}r^2\theta$。
4. **素養應用 · 哥德式尖拱建築**：古希臘埃拉托斯特尼測量地球半徑與哥德式尖拱窗幾何計算。
5. **CASIO 工程計算機模擬器**：Deg / Rad 模式精確切換與三角比計算。
6. **單元 01 觀念是非題 & 歷屆素養題庫**：即時診斷與自動計分。

### 🌊 單元 02：週期性數學模型 (Periodic Mathematical Models)
1. **單位圓投影與正弦波生成**：單位圓動點 $P(\cos x, \sin x)$ 鉛直高度動態展開為標準正弦波 $y = \sin x$。
2. **正弦函數圖形變換實驗室**：即時調控振幅 $a$、頻率 $b$、相位 $h$ 與鉛直位移 $k$（$y = a\sin(b(x-h)) + k$）。
3. **生活週期性現象三角函數建模**：
   - 🎡 **摩天輪旋轉車廂高度模型**
   - 🌊 **海港潮汐水深升降週期**
   - 🌓 **月相盈虧光照比例**
4. **單元 02 觀念是非題 & 經典素養題庫**：完整解析與觀念導正。
